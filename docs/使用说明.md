# image-curator 使用说明

> 图片「爬取 → 人工打分 → AI 自动学习筛选」本地工具
> 设计文档：[docs/PRD.md](PRD.md)　技术架构：[README.md](../README.md)

## 一、启动与关闭

| 操作 | 方法 |
|---|---|
| 启动 | 双击项目根目录的 **`启动.bat`**，3 秒后自动打开浏览器 |
| 地址 | http://127.0.0.1:5176 |
| 关闭 | 直接关掉黑色命令行窗口 |
| 端口占用 | 提示端口被占 = 已经在运行，直接用浏览器访问即可 |

**前置条件**：抓取 yande.re 需要先开启本地代理（默认 `http://127.0.0.1:12330`，可在 `config.json` 里改）。

## 二、日常使用流程

```
抓取任务（补货） → 打分（键盘标注） → 训练模型 → 审查修正（抓错） → 再训练 → 越来越准
```

### 1. ⬇️ 抓取任务

- 选数据源（目前：`yandere`，另有 `mock` 测试源）
- 填 tags，空格分隔，例如：
  - `white_thighhighs rating:s`（白丝 + 安全分级）
  - `pantyhose order:score`（裤袜按热度）
  - `chen_bin`（按画师）
- 填数量上限，代理留空则自动用 config.json 的默认代理
- 进度列含义：**搜到**（搜索引擎返回总数）· **新增**（去重后入库）· **下载**（实际落盘）
  - 「搜到 100 新增 0」= 这批图以前抓过，不是卡住
- 任务可「暂停/继续」；程序重启后中断的任务自动转为"已暂停"，点「继续」断点续跑

### 2. 🖊️ 打分

- 键盘操作（核心效率来源）：

  | 键 | 含义 |
  |---|---|
  | `1` | ♥ 喜欢（自动归档到 `data/favorites/`） |
  | `2` | ✕ 不喜欢 |
  | `3` | → 跳过（不进训练样本） |

- 顶部彩色徽章显示**预测分**：`预测 85.3%`，绿 ≥70% / 黄 40-70% / 红 <40% / 灰 = 尚无预测
- 「智能排序」开关：开 = 按预测分从高到低喂图（先看你最可能喜欢的）；关 = 按抓取顺序
- 每次切回打分页都会自动按最新排序取第一张

### 3. 🧠 模型与偏好

- **Zero-shot 冷启动粗筛**：0 标注时也能用 CLIP 文本提示先粗排一轮（可选）
- **训练模型**：喜欢+不喜欢 ≥10 条即可训练（建议 100+ 再开始，越多越好）
  - 原理：CLIP 图像特征 + 站点 tag → 逻辑回归；首次训练会给所有已下载图算向量，要等几分钟，之后增量很快
- 训练完成后看**偏好榜**：「喜欢的元素」里 `white_thighhighs` 等 tag 权重越高，说明模型越确定你爱这个

### 4. 🔍 审查修正（模型质检）

| 视图 | 用途 |
|---|---|
| 未标注·预测喜欢 | 模型猜你喜欢、你还没看过的——确认它猜得对不对 |
| 未标注·预测不喜欢 | 模型猜你讨厌的——翻一翻抓"漏网之鱼" |
| 全盘·预测喜欢 / 不喜欢 | 含已标注的全量核对 |
| 已喜欢 | 收藏夹核对 |

点 ♥ / ✕ 直接修正，修正立即作为新标注，下次训练生效。

## 三、数据都在哪

| 位置 | 内容 |
|---|---|
| `data/curator.db` | SQLite 数据库（图片元数据、标注、预测分、模型权重） |
| `data/incoming/` | 抓回来的全部原图 |
| `data/favorites/` | 你标"喜欢"的图（真正的收藏成品） |
| `data/models/` | CLIP 模型缓存 ~300MB（**别删**，删了要重下） |
| `config.json` | 端口/代理/存储目录/zero-shot 提示词配置 |

清空重来：删掉 `data/curator.db*` 和 incoming/favorites 里的文件即可（保留 models）。

## 四、常见问题

**Q：任务报 `connect ETIMEDOUT 157.240.x.x`？**
A：代理没开或没生效，那是 DNS 污染后的假 IP。确认代理客户端在跑且放行 yande.re。

**Q：抓取报 `yande.re API 返回错误: ...`？**
A：yande.re 匿名搜索有限制（tag 数量/页深），减少 tag 数量或分多次抓。

**Q：训练按钮是灰的？**
A：喜欢+不喜欢标注合计不足 10 条，先去打分页标注。

**Q：预测分好久不变？**
A：预测分只在「训练模型」时全量刷新。标注了一批新的就再点一次训练。

**Q：图片版权？**
A：仅供个人收藏学习，勿二次分发。

## 五、扩展方向（已预留）

- 新数据源：实现 `src/server/sources/` 里的 `SourcePlugin` 接口即可（如 Danbooru、Konachan、Pixiv）
- 存储后端：`StorageBackend` 接口已抽象，可扩展 WebDAV/OpenList 网盘归档
- 桌面壳：需要时可包 Electron/Tauri
